Project story

We built Quest Explorer to practice semantic HTML, a CSS variable design system, Grid and Flexbox, and motion that helps users.

Design trade-offs

We used only HTML and CSS, so the recommendation engine is a simulated interface rather than a live recommendation system.

Accessibility commitments

Our accessibility features include a skip link, visible keyboard focus, and reduced-motion support. We also aim to provide sufficient contrast and clear text labels.

Quest Explorer is a student HTML and CSS project. Fonts: Caprasimo and Atkinson Hyperlegible via Google Fonts (SIL Open Font License). All artwork is made with CSS. Meet the team.
